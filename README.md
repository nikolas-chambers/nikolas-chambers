### What I'm building

**[open-debugger](https://github.com/nikolas-chambers/open-debugger)** — an
OllyDbg-shaped Windows debugger on top of DbgEng: disassembly, registers,
stack and dump panes, an Olly-verb command bar, and a named pipe so a script
can drive the same live session a person is sitting in front of. It exports a
flat C plugin API modeled on Olly's, with its own
[SDK](https://github.com/nikolas-chambers/open-debugger-plugins_sdk) and
[plugins](https://github.com/nikolas-chambers/open-debugger-plugins).

**[SALEM!](https://nikolas-chambers.github.io/salem-site/)** — a tour guide to
Massachusetts' Witch City.
